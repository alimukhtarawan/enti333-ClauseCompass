# HireGuard

Alberta employment-contract triage in 60 seconds.

HireGuard is an AI-assisted, citation-backed triage tool for Alberta SME employers reviewing their employment contracts. It scores each contract across six Alberta-law categories (termination, restrictive covenants, statutory compliance, compensation, workplace rights, flexibility), surfaces every red flag with a citation traced to a real CanLII source, and shows side-by-side how raw AI tools (ChatGPT, raw Gemini) compare to HireGuard's structured output.

Built for **ENTI 633 — Generative AI and Prompting**, Spring 2026, Haskayne School of Business, University of Calgary.

## What's inside

- 5 pages: `/`, `/analyze`, `/contracts/[id]`, `/portfolio`, `/about`
- 2 API routes: `/api/analyze` (Gemini extraction → deterministic scoring) and `/api/compare` (parallel ChatGPT + raw Gemini)
- 20 deterministic Alberta-law scoring rules across six categories
- 5 pre-seeded contracts with hand-tuned reports — instant demo, zero outbound calls

## Run locally

```bash
# Node 20 LTS
npm install
cp .env.example .env.local   # set GEMINI_API_KEY and OPENAI_API_KEY
npm run dev                  # http://localhost:5000
```

On Replit, set `GEMINI_API_KEY` and `OPENAI_API_KEY` in Secrets.

## Architecture

| Layer | Tool | What it does |
| --- | --- | --- |
| 1. Extraction | Gemini 2.5 Flash | Reads contract text, returns structured JSON. Forbidden from emitting statutes or case law. |
| 2. Scoring | Deterministic rules engine | Applies 20 rules. Citations are string constants in `lib/scoring/*.ts`. CanLII URLs from `CANLII_URLS` map only. |
| 3. Comparison panel | OpenAI gpt-4o-mini + raw Gemini | Editorial side-by-side display only — never feeds into scoring. Hallucinated citations flagged in real time. |

## Disclaimer

HireGuard is a student project. It is not a law firm and does not provide legal advice. The summaries, risk scores, red flags, and questions produced by this product are generated by automated tools and may be incomplete or incorrect. HireGuard's outputs are intended to help an Alberta employer identify and prioritize possible risks in employment agreements so they can decide when to seek qualified legal advice. Always consult a lawyer licensed by the Law Society of Alberta before acting on any output from this product. Use of HireGuard does not create a solicitor-client relationship.
